WHAT YOU CAN USE TODAY

A useful start. Clear limits.

The download is a runnable personal workspace. This website is an independent simulation, not a hosted personal-data service.

01

Meals + fitness

Manual meals, review and confirmation, daily activity and workouts. Daily totals, optional goals, local SQLite and a Markdown knowledge base. No GPT needed.

02

Choose your extras

Finance is off by default and explicitly enabled. Optional model adapters use your own setup. AI chat does not automatically write meal or workout records.

03

Not included

An iOS app, bank sync, the maintainer's private memory or production Hermes Gateway. A compatible local chat endpoint can be configured separately; no private service is exposed here.

FORK IT. MAKE IT YOURS.

Start recording in minutes.

Download and unpack the latest preview. With Python 3.10+ installed, open a terminal in that folder and run:

python3 scripts/hermes.py start --open

Windows: py -3. Or use the included macOS / Windows launcher. No Git, Codex, or API key required.
