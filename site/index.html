THE HONEST VERSION

A starter. Not a promise.

The downloadable preview is a small, runnable local workspace. This public website is a separate, scripted walkthrough.

01

What runs today

Manual career, nutrition, activity, and expense records. A local dashboard, SQLite storage, and a Markdown knowledge base.

02

What you opt into

Model adapters and integrations require your own setup. The default Echo adapter is an offline connectivity test, not an AI assistant.

03

What isn't included

The owner's private memory and accounts, automatic applications, bank sync, and a finished Research Lab. No private service is exposed here.

TAKE THE NEXT SMALL STEP

Try it on your own machine.

Download and unpack the source. With Python 3.10+ installed, open a terminal in that folder and run:

python3 scripts/hermes.py start --demo --open

Windows: replace python3 with py -3. No Git, Codex, or API key required.
