# START HERE

This is the entry file for a portable long-term memory layer.

If you are an AI assistant helping this user, read this first.

---

## First Steps

1. Read `Index/master_index.md`.
2. Follow `Workflows/personal_memory_policy.md`.
3. For life/project/decision updates, use `Workflows/personal_memory_triage.md`.
4. Ask before saving sensitive or uncertain information.
5. Important memory goes into markdown files, not only internal agent memory.

---

## User Shortcut

The user does not need to remember the whole folder structure.

They can say:

```text
Please read START_HERE.md first, then help me process the following update.
```

or:

```text
This may be worth saving. Please triage it first and wait for my confirmation.
```

---

## Core Rule

Use internal memory for short, stable, non-sensitive index facts.

Use markdown files for durable long-term memory.

Do not save random chat fragments or sensitive information automatically.
